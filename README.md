# Healthcare Member Demographics & Regional Analysis Dashboard

## 📊 Project Overview

This project focuses on analyzing healthcare member data and presenting meaningful demographic and regional insights through an interactive **Power BI dashboard**.

The project uses healthcare member data containing demographic and analytical fields. A regional classification was created based on the member's **Original Preferred Language**, allowing the data to be analyzed across four major regions: **APAC, EMEA, USCA, and Other**.

## 📁 Project Files

* `Data for healthcare analyst.xlsx` – Source healthcare dataset

## 🔄 Project Workflow

1. Imported the healthcare dataset into Power BI.
2. Reviewed and prepared the source data for analysis.
3. Created a calculated **Region** field using DAX.
4. Mapped Original Preferred Language into regional categories.
5. Created interactive visualizations and analytical reports.
6. Used the Power BI dashboard to explore healthcare member demographics and regional patterns.

## 🌍 Regional Classification

The project classifies preferred languages into four major regions:

* **APAC** – Asia-Pacific
* **EMEA** – Europe, Middle East, and Africa
* **USCA** – United States and Canada
* **Other** – Languages that are not explicitly mapped or are unknown

For example, the provided mapping assigns languages such as Hindi, Mandarin, Japanese, and Korean to APAC, while Arabic, French, Polish, and Romanian are mapped to EMEA.
